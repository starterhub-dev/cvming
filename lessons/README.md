# Lesson 03: Gradient Descent 梯度下降

这是 TinyMind 的第一个机器学习练习。只使用 Python 标准库，不需要 API、付费服务或 GPU。

## 在手机上运行

1. 打开 [Google Colab](https://colab.research.google.com/#create)。
2. 新建笔记本，把 `gradient_descent.py` 的代码复制到代码单元格。
3. 点击运行，观察 loss（误差）逐步下降。
4. 修改 `LEARNING_RATE`，每次从头运行完整代码，对比结果。

## 实验任务

依次尝试：

- `LEARNING_RATE = 0.001`：步子较小，1000 轮后可能仍有明显误差。
- `LEARNING_RATE = 0.01`：基准实验，参数通常会接近 w=2、b=1。
- `LEARNING_RATE = 0.1`：步子更大，可能更快，也可能震荡或发散。

每次实验都要从 `w = 0.0`、`b = 0.0` 开始，才方便公平比较。

## 关键概念

- **模型**：本练习使用 `y_hat = w * x + b`。
- **损失函数**：平均平方误差，衡量预测和正确答案相差多少。
- **梯度**：告诉我们损失随参数变化的方向和幅度。
- **学习率**：控制每次更新参数的步幅。
- **训练轮次（epoch）**：模型完整遍历一次训练数据算一轮。

## 预期结果

训练数据是 (1,3)、(2,5)、(3,7)、(4,9)、(5,11)，其规律是 y=2x+1。
在学习率 0.01、训练 1000 轮时，参数会接近 w=2、b=1，输入 x=6 时预测接近 13。

## 自测

模型在训练数据上误差很低，但在没见过的数据上预测很差，可能是什么问题？
